1. Начало
2. Вводим переменные: x, y, z
3. Вычисляем a = fabs(cos(x) - cos(y))
4. Вычисляем b = pow(a, 1 + pow(sin(y), 2)*2)
5. Вычисляем c = 1 + z + pow(z, 2) / 2 + pow(z, 3) / 3 + pow(z, 4) / 4
6. Вычисляем и выводим на экран w = b*c
